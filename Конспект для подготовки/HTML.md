#### Маршрут

1. Понять роль HTML как структуры документа.
2. Разобрать семантику, доступность, ARIA и keyboard/focus.
3. Понять формы как нативный механизм ввода и отправки данных.
4. Разобрать `<head>`, meta, SEO, scripts и resource hints.
5. Связать изображения с accessibility, адаптивом и Core Web Vitals.
6. Связать HTML с [[Конспект для подготовки/Web Basics/Critical Render Path|Critical Render Path]].
