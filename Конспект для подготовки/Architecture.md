#### Маршрут

1. Начать с общей архитектуры: границы слоёв, зависимости, feature-модули.
2. Разобрать frontend system design: требования, state ownership, API, UI states, performance, тесты.
3. Разобрать FSD: layers, slices, segments, import rule, public API.
4. Связать архитектуру с принципами: SOLID, composition, узкие контракты, dependency direction.
5. Разобрать прикладные паттерны: Adapter/Facade для API/SDK, Factory/Singleton для lifecycle сервисов.
6. Разобрать state: local, server, URL, form и global state.
7. Закрыть API-слой: OpenAPI/Swagger, контракты, DTO, runtime validation, ошибки, отмена запросов.
8. Понять production-качество: error handling, observability, source maps, PII.
9. Повторить управляемые релизы: feature flags, rollout, kill switch.
10. Отдельно держать microfrontends как trade-off, а не универсальный ответ.
11. Связать архитектуру с delivery: Docker, CI/CD, env variables, artifacts и rollback.
