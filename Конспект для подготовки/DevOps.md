#### Маршрут

1. Понять Docker: image, container, registry, build context, layers.
2. Разобрать frontend Dockerfile: build stage, runtime stage, `.dockerignore`, кеш слоёв.
3. Понять отдачу SPA/SSR: Nginx для статических файлов, Node runtime для SSR/Next.js.
4. Закрыть env variables и секреты: build-time, runtime, GitLab variables, публичный frontend bundle.
5. Разобрать GitLab CI/CD: stages, jobs, rules, runners, artifacts, cache.
6. Собрать типовой pipeline: install, lint, test, build, docker image, deploy.
7. Проверить безопасность: protected variables, registry login, отсутствие секретов в artifacts/logs.
