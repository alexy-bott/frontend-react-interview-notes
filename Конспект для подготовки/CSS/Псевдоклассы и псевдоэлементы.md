#### Ответ на 60 секунд

Псевдоклассы и псевдоэлементы расширяют возможности CSS-селекторов без изменения HTML. Псевдокласс описывает состояние или положение элемента, например `:hover`, `:focus-visible`, `:checked`, `:nth-child`. Псевдоэлемент описывает виртуальную часть элемента, например `::before`, `::after`, `::placeholder`, `::selection`.

Коротко: `:` - состояние или условие выбора элемента, `::` - часть элемента. Разница в объекте стилизации: псевдокласс выбирает сам элемент в определенном состоянии, а псевдоэлемент стилизует часть содержимого или создает виртуальный фрагмент.

#### Ключевая схема

| Тип | Синтаксис | Примеры |
| --- | --- | --- |
| Псевдокласс | `:` | `:hover`, `:focus`, `:not`, `:has` |
| Псевдоэлемент | `::` | `::before`, `::after`, `::placeholder` |

#### Развернутый ответ

Псевдокласс выбирает сам элемент по состоянию, положению или условию: `:hover`, `:focus-visible`, `:checked`, `:nth-child`, `:has`. Псевдоэлемент стилизует виртуальную часть элемента: `::before`, `::after`, `::placeholder`, `::selection`.

`:is()` группирует селекторы и берёт специфичность самого специфичного селектора внутри. Он помогает писать короче, но может поднять вес правила, если внутри оказался id или сложный селектор.

`:where()` тоже группирует селекторы, но всегда имеет нулевую специфичность. Это удобно для base styles, reset и правил, которые должны легко переопределяться компонентами.

`:has()` позволяет выбрать элемент по наличию подходящего потомка или связанного элемента. Его часто называют parent selector, но он шире: можно описывать зависимость от внутренней структуры, состояния соседей или вложенных controls.

Псевдоэлементы `::before` и `::after` требуют `content`, иначе виртуальный фрагмент не появится. Их используют для декора, иконок, badges и визуальных деталей, но не для важного контента, который должен быть доступен assistive technologies.

> [!faq]+ Уточнения
> - `:` выбирает элемент в состоянии/условии, `::` стилизует часть элемента.
> - `:focus-visible` отделяет keyboard focus UX от обычного pointer-взаимодействия.
> - `:is()` берёт specificity от аргументов.
> - `:where()` имеет нулевую specificity.
> - `::before`/`::after` требуют `content`.

#### Пример

```css
button:focus-visible {
  outline: 2px solid dodgerblue;
}

.field:has(input:invalid) {
  color: crimson;
}

.badge::before {
  content: "";
  display: inline-block;
  width: 8px;
  height: 8px;
  border-radius: 50%;
  background: currentColor;
}
```

#### Частые ошибки

- Путать псевдокласс и псевдоэлемент.
- Использовать `:focus` вместо `:focus-visible` для keyboard UX.
- Забывать `content` у `::before` и `::after`.
- Не учитывать специфичность `:is()`, `:not()` и `:has()`.
- Использовать псевдоэлементы для важного контента, который должен быть доступен скринридеру.
