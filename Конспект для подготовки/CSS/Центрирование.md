#### Быстрый ответ

Центрирование в CSS выбирают по двум вопросам: что именно центрируем и по какой оси. Для блочного элемента по горизонтали часто достаточно ограничить ширину и поставить `margin-inline: auto`. Для текста и inline-элементов работает `text-align: center` на родителе. Если нужно центрировать элемент по двум осям и его размер заранее неизвестен, самый практичный вариант - Flexbox или Grid.

Для двух осей в normal flow часто используют Grid с `place-items: center` или Flexbox с `justify-content` и `align-items`. `absolute/fixed` плюс `transform: translate(-50%, -50%)` подходит для overlay, который намеренно не должен занимать место в layout. Выбор определяется не длиной CSS, а нужным поведением соседей, переполнения и нескольких элементов.

#### Ключевая схема

| Задача | Решение |
| --- | --- |
| Блочный элемент по горизонтали | `width/max-width` + `margin-inline: auto` |
| Текст или inline-элементы | `text-align: center` |
| Один элемент по двум осям | `display: grid; place-items: center` |
| Несколько элементов по двум осям | `display: flex; justify-content: center; align-items: center` |
| Overlay поверх интерфейса | `position: fixed/absolute` + `transform` |
| Полноэкранное центрирование | `min-height: 100dvh` у контейнера |

#### Базовая модель

Нужно определить:

1. Центрируется текст/inline content или самостоятельный box.
2. Нужна inline axis, block axis или обе оси.
3. Элемент должен оставаться в normal flow или накладываться поверх него.
4. Что должно произойти, если содержимое больше контейнера.

Физические «горизонтально/вертикально» удобны для привычного writing mode, но CSS Box Alignment оперирует осями. У Flexbox `justify-content` работает вдоль main axis, которая зависит от `flex-direction`, а `align-items` - вдоль cross axis.

#### Развернутый ответ

Центрирование зависит от типа элемента и оси. Блочный элемент по горизонтали центрируют через ограничение ширины и `margin-inline: auto`. Текст и inline-содержимое центрируют через `text-align: center` на родителе. Для двух осей используют Grid/Flexbox, если элемент остаётся в нормальном потоке.

`margin: auto` по горизонтали работает, когда у блочного элемента есть ограниченная ширина. Если элемент занимает всю доступную ширину (`width: auto`), auto-отступам нечего делить. Поэтому обычно задают `width`, `max-width` или `width: min(...)`.

В Grid `place-items: center` центрирует элементы внутри их grid areas. Это не то же самое, что `place-content: center`, которое распределяет всю grid-сетку внутри контейнера при наличии свободного места. Flexbox удобен для ряда или колонки элементов, где нужно управлять направлением, `gap` и распределением по main axis.

`absolute/fixed + transform` используют для overlays: modal, tooltip, badge, floating button. Такой элемент выпадает из обычного потока, поэтому нужно учитывать containing block, stacking context, scroll, viewport и адаптивность.

На мобильных экранах `100vh` не всегда соответствует видимой области при изменении browser UI. `100svh` даёт стабильную безопасную высоту, а `100dvh` следует текущей области и может изменяться во время прокрутки. Для длинного контента используют `min-height`, а не фиксированный `height`, чтобы сохранить возможность роста и прокрутки.

#### Пример

```css
/* Один блок по центру экрана */
.page {
  min-height: 100svh;
  display: grid;
  place-items: center;
  padding: 16px;
}

.card {
  width: min(100%, 420px);
}
```

```css
/* Группа элементов по центру через Flexbox */
.actions {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 12px;
}
```

```css
/* Блочный элемент по горизонтали */
.container {
  max-width: 960px;
  margin-inline: auto;
  padding-inline: 16px;
}
```

#### Ключевые уточнения

- `text-align` выравнивает inline content внутри box, а не сам block box.
- Auto margins распределяют свободное пространство; у box на всю доступную ширину такого пространства может не быть.
- Во Flexbox ось `justify-content` зависит от `flex-direction`.
- `place-items` выравнивает items в их областях, а `place-content` - всю сетку внутри контейнера.
- `absolute` и `fixed` не резервируют место, поэтому для обычного layout предпочтительнее Grid/Flexbox.
- Для неизвестной высоты контента полноэкранный контейнер задают через `min-height` и проверяют overflow.
