#### Ответ на 60 секунд

Центрирование в CSS выбирают по двум вопросам: что именно центрируем и по какой оси. Для блочного элемента по горизонтали часто достаточно ограничить ширину и поставить `margin-inline: auto`. Для текста и inline-элементов работает `text-align: center` на родителе. Если нужно центрировать элемент по двум осям и его размер заранее неизвестен, самый практичный вариант - Flexbox или Grid.

В современном CSS для двух осей часто используют `display: grid; place-items: center` как самый короткий синтаксис или Flexbox с `justify-content: center` и `align-items: center`, если в контейнере есть несколько элементов и нужно управлять направлением. `position: absolute/fixed` плюс `transform: translate(-50%, -50%)` тоже работает, но элемент выпадает из потока, поэтому этот способ подходит для overlays, tooltip, modal и похожих случаев.

#### Ключевая схема

| Задача | Решение |
| --- | --- |
| Блочный элемент по горизонтали | `width/max-width` + `margin-inline: auto` |
| Текст или inline-элементы | `text-align: center` |
| Один элемент по двум осям | `display: grid; place-items: center` |
| Несколько элементов по двум осям | `display: flex; justify-content: center; align-items: center` |
| Overlay поверх интерфейса | `position: fixed/absolute` + `transform` |
| Полноэкранное центрирование | `min-height: 100dvh` у контейнера |

#### Развернутый ответ

Центрирование зависит от типа элемента и оси. Блочный элемент по горизонтали центрируют через ограничение ширины и `margin-inline: auto`. Текст и inline-содержимое центрируют через `text-align: center` на родителе. Для двух осей используют Grid/Flexbox, если элемент остаётся в нормальном потоке.

`margin: auto` по горизонтали работает, когда у блочного элемента есть ограниченная ширина. Если элемент занимает всю доступную ширину (`width: auto`), auto-отступам нечего делить. Поэтому обычно задают `width`, `max-width` или `width: min(...)`.

Grid короче для одного элемента по центру: `display: grid; place-items: center`. Flexbox удобен для группы элементов, toolbar, actions row, карточек и ситуаций, где нужно управлять направлением, gap и распределением вдоль одной оси.

`absolute/fixed + transform` используют для overlays: modal, tooltip, badge, floating button. Такой элемент выпадает из обычного потока, поэтому нужно учитывать containing block, stacking context, scroll, viewport и адаптивность.

На мобильных экранах `100vh` может конфликтовать с адресной строкой и системным UI. `100dvh` отражает динамическую высоту viewport и уменьшает проблемы с прыгающим вертикальным центрированием.

> [!faq]+ Уточнения
> - Блочный элемент по горизонтали: `max-width` + `margin-inline: auto`.
> - Inline/text: `text-align: center` на родителе.
> - Один элемент по двум осям: Grid + `place-items: center`.
> - Группа элементов: Flexbox с `justify-content` и `align-items`.
> - Overlay: `position` + `transform`, но с учётом stacking context и scroll.

#### Пример

```css
/* Один блок по центру экрана */
.page {
  min-height: 100dvh;
  display: grid;
  place-items: center;
  padding: 16px;
}

.card {
  width: min(100%, 420px);
}
```

```css
/* Группа элементов по центру через Flexbox */
.actions {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 12px;
}
```

```css
/* Блочный элемент по горизонтали */
.container {
  max-width: 960px;
  margin-inline: auto;
  padding-inline: 16px;
}
```

#### Частые ошибки

- Использовать `text-align: center` и ожидать, что он сдвинет блочный элемент.
- Ставить `margin-inline: auto` без ограничения ширины.
- Центрировать через `position: absolute`, когда layout проще решить Flexbox или Grid.
- Забывать, что `absolute` и `fixed` убирают элемент из обычного потока.
- Не учитывать мобильную высоту viewport и использовать `100vh` там, где нужен `100dvh`.
