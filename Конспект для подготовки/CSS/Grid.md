#### Быстрый ответ

CSS Grid - это модель раскладки для двумерных сеток, где одновременно управляют строками и колонками. Grid хорошо подходит для layouts страниц, карточных сеток, таблиц интерфейса и областей, где важны и горизонтальные, и вертикальные связи.

Grid задаёт tracks через `grid-template-columns` и `grid-template-rows`, расстояния через `gap`, а элементы размещает явно или алгоритмом auto-placement. `fr` распределяет свободное место, `minmax()` задаёт границы трека, а `auto-fit`/`auto-fill` позволяют числу колонок зависеть от доступной ширины.

#### Ключевая схема

| Задача | Инструмент |
| --- | --- |
| Создать grid-контейнер | `display: grid` |
| Задать колонки | `grid-template-columns` |
| Задать строки | `grid-template-rows` |
| Расстояние между ячейками | `gap` |
| Доля свободного места | `fr` |
| Ограничить размер трека | `minmax()` |
| Повторить шаблон | `repeat()` |
| Адаптивная сетка | `repeat(auto-fit, minmax(...))` |
| Разместить элемент | `grid-column`, `grid-row` |

#### Базовая модель

Grid container образует линии, между которыми находятся tracks; пересечение row и column track создаёт cell. Несколько cells формируют grid area. Tracks, объявленные в `grid-template-*`, входят в explicit grid. Если элемент размещён за её границами или auto-placement создаёт новые строки/колонки, появляется implicit grid.

Алгоритм сначала учитывает фиксированные и intrinsic размеры содержимого, min/max-ограничения и gaps. После этого `fr` делит оставшееся свободное пространство. Поэтому `1fr` не означает «любым способом занять ровно одну долю контейнера».

#### Развернутый ответ

Grid управляет строками и колонками одновременно. Flexbox раскладывает элементы по одной оси за раз, поэтому подходит для toolbar, меню и выравнивания в линии. Grid подходит для карточных сеток, layouts страниц, областей с фиксированными зонами и случаев, где важны связи по двум направлениям.

Основные сущности Grid - container, tracks, cells, gaps и placement. `grid-template-columns` и `grid-template-rows` задают треки, `gap` задаёт расстояния, `grid-column`/`grid-row` размещают элементы. Auto-placement сам раскладывает элементы, если не задавать позиции вручную.

У track `1fr` по умолчанию остаётся автоматический минимум, который может быть равен минимальному размеру содержимого. Поэтому длинный текст способен вызвать overflow. `minmax(0, 1fr)` явно разрешает треку сжаться ниже min-content; содержимое при этом тоже должно уметь переноситься или обрезаться.

`auto-fill` создаёт максимальное число подходящих tracks и сохраняет пустые. `auto-fit` после размещения схлопывает пустые tracks, поэтому занятые могут растянуться. Для карточек часто подходит `repeat(auto-fit, minmax(min(100%, 240px), 1fr))`: вложенный `min()` не позволяет минимальному track стать шире самого узкого контейнера.

`subgrid` позволяет вложенному grid item использовать tracks родительской Grid по выбранной оси. Это полезно, когда внутренние элементы нескольких карточек должны выровняться по одним линиям. Обычная вложенная Grid рассчитывает свои tracks независимо.

#### Пример

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 240px), 1fr));
  gap: 16px;
}

.featured {
  grid-column: span 2;
}
```

Количество колонок меняется по доступной ширине. На контейнере уже `240px` остаётся одна колонка без горизонтального overflow из-за жёсткого минимума.

#### Ключевые уточнения

- `fr` делит свободное пространство после обязательных размеров и gaps.
- Автоматический минимум `1fr` может вызвать overflow; для разрешённого сжатия используют `minmax(0, 1fr)`.
- Explicit и implicit grid могут иметь разные размеры tracks; implicit tracks настраиваются через `grid-auto-*`.
- `auto-fit` схлопывает пустые tracks, `auto-fill` сохраняет их.
- Визуальное размещение не должно нарушать логический DOM-порядок и последовательность фокуса.
- Flexbox удобнее для одной линии, Grid - когда связи строк и колонок являются частью модели layout.
