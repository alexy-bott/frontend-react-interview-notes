#### Маршрут

1. Начать с нативной базы: `<form>`, `label`, `name`, submit, `FormData`, accessibility.
2. Разобрать controlled и uncontrolled подходы в React.
3. Понять React Hook Form: `useForm`, `register`, `handleSubmit`, `formState`.
4. Закрыть кастомные компоненты: `Controller`, Radix UI, select/checkbox/radio.
5. Разобрать validation: HTML constraints, schema validation, Zod/Yup resolver.
6. Закрыть server errors и async validation: `422`, field errors, `setError`, debounce, race conditions.
7. Понять submit lifecycle: dirty, touched, pending, reset, optimistic UI.
8. Связать формы с архитектурой: DTO, API layer, feature modules, accessibility и тесты.
9. Разобрать system design формы: async validation, server errors, pending, draft и восстановление.
