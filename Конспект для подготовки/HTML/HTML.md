#### Ответ на 60 секунд

HTML - это язык разметки, который описывает структуру и смысл содержимого веб-страницы. Он не отвечает за внешний вид как CSS и не отвечает за поведение как JavaScript. Его задача - дать браузеру, поисковикам, скринридерам и другим инструментам понятную структуру документа.

HTML - это не просто набор `div`. Важны семантические теги, корректная иерархия заголовков, доступные формы, правильные атрибуты, альтернативный текст для изображений и валидная вложенность. Чем точнее структура HTML, тем проще стилизовать интерфейс, поддерживать код, улучшать SEO и доступность.

#### Ключевая схема

| Часть HTML | Зачем нужна |
| --- | --- |
| Семантические теги | смысловая структура документа |
| Заголовки `h1-h6` | иерархия контента |
| Формы | ввод данных пользователем |
| Атрибуты | дополнительная информация и поведение |
| ARIA | дополнение семантики, когда HTML не хватает |

#### Развернутый ответ

HTML - язык разметки, а не язык программирования. Он описывает структуру документа: какие части страницы являются заголовками, навигацией, основным содержимым, формами, списками, таблицами, ссылками и действиями. Браузер парсит HTML в DOM, а затем CSS и JavaScript работают уже поверх этой структуры.

Семантика HTML влияет на встроенное поведение. `<button>` уже доступен с клавиатуры, имеет роль кнопки и корректно участвует в форме. `<a>` создаёт ссылку и ожидаемую навигацию. `<label>` связывает текст с полем ввода. Если заменить всё на `div`, придётся вручную восстанавливать роли, фокус, клавиатуру и состояния, и легко получить недоступный интерфейс.

Валидная вложенность тоже важна. HTML parser умеет исправлять ошибки, но может построить DOM не так, как ожидал разработчик. Например, некорректная вложенность интерактивных элементов, таблиц или paragraph/content model может привести к странной структуре DOM, проблемам со стилями и недоступному поведению.

ARIA дополняет HTML, когда нативной семантики недостаточно, но не заменяет правильный элемент. Сначала выбирают подходящий HTML-тег, затем добавляют `aria-*` только для недостающего состояния, описания или роли в сложном custom UI.

> [!faq]+ Уточнения
> - HTML описывает структуру и смысл документа, но не содержит алгоритмов как JavaScript.
> - DOM - результат парсинга HTML, с которым затем работают CSSOM, layout и JavaScript.
> - Семантический элемент даёт роль, поведение и доступность без ручного воспроизведения.
> - Невалидная вложенность может изменить итоговый DOM.
> - ARIA используют как дополнение, а не как первую замену нативного HTML.

#### Пример

```html
<main>
  <article>
    <h1>Что такое HTML</h1>
    <p>HTML описывает структуру и смысл страницы.</p>
    <button type="button">Подробнее</button>
  </article>
</main>
```

#### Частые ошибки

- Верстать всё через `div` и терять семантику.
- Делать кнопку через `div` вместо `<button>`.
- Нарушать порядок заголовков ради размера текста.
- Забывать `label` у полей формы.
- Использовать `alt` как формальность, а не как текстовую альтернативу.
