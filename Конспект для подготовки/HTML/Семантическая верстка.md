#### Быстрый ответ

Семантическая вёрстка выбирает HTML-элементы по назначению содержимого и действия, а не по внешнему виду. `<nav>` обозначает навигацию, `<article>` - самостоятельный материал, `<button>` - действие, а `<a href>` - переход к адресу.

Такой выбор даёт браузеру и вспомогательным технологиям правильные роли, связи и нативное поведение, а разработчику - понятную структуру. `div` и `span` остаются нормальными нейтральными контейнерами, когда у части интерфейса нет более точного смысла.

#### Ключевая схема

| Смысл | Подходящий элемент | Важная граница |
| --- | --- | --- |
| Основное содержимое | `<main>` | обычно одна видимая основная область документа |
| Набор навигационных ссылок | `<nav>` | не каждая группа ссылок является отдельной навигацией |
| Самостоятельный материал | `<article>` | сохраняет смысл вне текущей страницы |
| Тематический раздел | `<section>` | обычно имеет доступный заголовок |
| Дополнительное содержимое | `<aside>` | связано с основным, но не является его ядром |
| Действие | `<button>` | не выполняет навигацию по URL |
| Навигация | `<a href>` | без `href` элемент не является обычной ссылкой |

#### Базовая модель

Сначала определяют тип содержимого или действия, затем выбирают элемент и только потом стилизуют его. Визуальная карточка может быть `<article>`, `<li>` или `<div>` в зависимости от смысла; одинаковый CSS не требует одинакового HTML.

Landmark-области помогают быстро перемещаться по странице. `<main>` обозначает основное содержимое, `<nav>` - навигацию, `<aside>` - дополнительную область. `<header>` и `<footer>` описывают вводную и завершающую часть ближайшего sectioning context; вложенный `<header>` не всегда становится отдельным page landmark.

Заголовки `h1`-`h6` формируют явную иерархию содержимого. Уровень выбирают по вложенности раздела, а размер задают CSS. Не стоит полагаться на воображаемый автоматический outline от вложенных `<section>`: браузеры и screen readers используют реальные уровни headings.

#### Развернутый ответ

**`section`, `article` и `div`.** `<section>` группирует тематически связанное содержимое, которое обычно можно назвать заголовком. `<article>` подходит самостоятельному материалу: новости, посту, комментарию, карточке товара при соответствующем контексте. `<div>` используется, если дополнительная семантика была бы выдуманной.

**`button` и `a`.** Кнопка изменяет состояние или запускает операцию: открывает dialog, отправляет форму, переключает режим. Ссылка имеет destination URL и сохраняет поведение навигации: контекстное меню, копирование адреса, открытие в новой вкладке. CSS может сделать ссылку похожей на кнопку, но не меняет её назначение.

**Списки и таблицы.** Набор однородных пунктов размечают `<ul>`/`<ol>` и `<li>`. Таблица предназначена для данных с отношениями строк и столбцов, а не для layout. Корректные `<th>` и области заголовков помогают сопоставлять ячейки.

**ARIA.** Нативный элемент выбирают первым. ARIA добавляет недостающее доступное имя, состояние или связь для сложного виджета, но не создаёт keyboard behavior. `role="button"` на `div` оставляет разработчику реализацию focus, `Enter`, `Space` и disabled state.

#### Пример

```html
<header>
  <nav aria-label="Основная навигация">
    <a href="/catalog">Каталог</a>
    <a href="/profile">Профиль</a>
  </nav>
</header>

<main>
  <article>
    <h1>Как выбрать ноутбук</h1>
    <section aria-labelledby="screen-heading">
      <h2 id="screen-heading">Экран</h2>
      <p>Сравните диагональ, разрешение и тип матрицы.</p>
    </section>
  </article>
</main>
```

`aria-labelledby` здесь не обязателен для обычного чтения заголовка, но явно именует section как region для accessibility tree. Если на странице много однотипных regions, такое именование помогает их различать.

#### Ключевые уточнения

- Семантику определяет назначение, а не имя CSS-класса и не внешний вид элемента.
- `<section>` нужен реальному тематическому разделу; нейтральная layout-обёртка остаётся `<div>`.
- Реальные уровни `h1`-`h6` отражают структуру; визуальный размер heading задаётся отдельно.
- `<button>` выполняет действие, `<a href>` выполняет навигацию. Сходный дизайн не делает их взаимозаменяемыми.
- ARIA дополняет правильный HTML и не воспроизводит нативное поведение автоматически.
