#### Ответ на 60 секунд

Семантическая верстка - это HTML-разметка, где теги выбираются по смыслу содержимого, а не только ради внешнего вида. Например, для навигации используют `<nav>`, для основного контента - `<main>`, для самостоятельной статьи - `<article>`, для кнопки - `<button>`.

Семантика важна для доступности, SEO, поддержки кода и встроенного поведения браузера. Скринридер получает понятную структуру страницы, поисковик точнее интерпретирует контент, а разработчику проще читать и сопровождать разметку. `div` и `span` не запрещены; их используют там, где нет более точного смыслового элемента.

#### Ключевая схема

| Тег | Смысл |
| --- | --- |
| `<header>` | вводная часть страницы или раздела |
| `<nav>` | блок навигации |
| `<main>` | основное уникальное содержимое страницы |
| `<section>` | тематический раздел |
| `<article>` | самостоятельный контент |
| `<aside>` | дополнительная связанная информация |
| `<footer>` | нижняя часть страницы или раздела |
| `<button>` | действие |
| `<a>` | переход по ссылке |

#### Развернутый ответ

Семантическая верстка начинается с вопроса о смысле элемента. Если блок является основной областью страницы, подходит `<main>`. Если это навигация - `<nav>`. Если это самостоятельный материал, который можно вынести отдельно, - `<article>`. Если это тематический раздел внутри страницы, обычно с собственным заголовком, - `<section>`.

`div` и `span` остаются нормальными элементами для layout и стилизации, когда дополнительного смысла нет. Ошибка возникает не в использовании `div`, а в замене им интерактивных или смысловых элементов: кнопок, ссылок, списков, заголовков, формовых controls и landmarks.

`button` и `a` различаются по назначению. `button` запускает действие в текущем интерфейсе: submit, open modal, toggle state, add item. `a` ведёт к URL или якорю и участвует в навигации. Стили не должны менять семантический выбор: ссылку можно сделать визуально похожей на кнопку, но смысл элемента остаётся навигационным.

ARIA используют после выбора HTML-элемента. Нативный элемент уже содержит роль, keyboard behavior и ожидаемую поддержку assistive technologies. `role="button"` на `div` требует вручную реализовать фокус, `Enter`/`Space`, disabled state и доступное имя.

> [!faq]+ Уточнения
> - `section` подходит для тематического раздела, `div` - для обёртки без смысла.
> - `<main>` обычно один на страницу и содержит уникальный основной контент.
> - `<button>` - действие, `<a>` - переход.
> - ARIA дополняет семантику, но не исправляет неверный выбор HTML автоматически.
> - Иерархия headings должна отражать структуру контента, а размер задаётся CSS.

#### Пример

```html
<header>
  <nav aria-label="Основная навигация">
    <a href="/catalog">Каталог</a>
    <a href="/profile">Профиль</a>
  </nav>
</header>

<main>
  <article>
    <h1>Как выбрать ноутбук</h1>
    <p>Короткое введение в статью.</p>
  </article>
</main>
```

#### Частые ошибки

- Использовать `<div onClick>` вместо `<button>`.
- Выбирать тег по внешнему виду, а не по смыслу.
- Делать несколько `<main>` на одной странице.
- Использовать `<section>` без реального раздела.
- Нарушать иерархию заголовков.
