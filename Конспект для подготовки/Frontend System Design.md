#### Маршрут

1. Начать с общей рамки проектирования фичи: требования, данные, state, API, ошибки, performance, тесты.
2. Разобрать таблицу как частый системный вопрос: filters, sorting, pagination, URL state, cache key, empty/loading/error.
3. Разобрать форму: form state, validation, async checks, server errors, submit lifecycle, accessibility.
4. Разобрать auth: login, refresh, protected routes, roles, logout, cache cleanup.
5. Разобрать realtime: выбор транспорта, snapshot + events, reconnect, cache updates, backpressure.
6. В каждом сценарии связывать решение с уже существующими темами: API layer, state management, forms, testing, security, performance.
