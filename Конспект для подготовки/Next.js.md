#### Маршрут

1. Начать с версии: что относится к Next.js 14, а что появилось или изменилось в более новых версиях.
2. Разобрать App Router: `app`, `page.tsx`, `layout.tsx`, nested routes, route groups, loading/error boundaries.
3. Понять Server Components и Client Components: где выполняется код, что попадает в bundle, где можно использовать state/effects/browser APIs.
4. Сравнить rendering strategies: static rendering, dynamic rendering, SSR, SSG, ISR, streaming.
5. Разобрать data fetching и cache: `fetch`, `cache`, `no-store`, `revalidate`, `revalidatePath`, `revalidateTag`.
6. Понять Server Actions и Route Handlers: мутации, формы, API endpoints, webhooks.
7. Закрыть production: env variables, Docker, Node runtime, static export, cache в self-hosted окружении.
