# Архив автономного workflow заметок

Этот каталог содержит **неактивную историческую governance**.

`legacy-root/` — точная копия полного локального mixed rule-set, сохранённого перед миграцией 23 августа 2026 года. Файлы внутри `legacy-root/` не переписаны и не нормализованы.

Происхождение комплекта смешанное:

- `_templates/repository-rules.md` и `_templates/note-rules/01-file-structure.md` совпадали с опубликованным `main` на `5d01970aa38d7cba1a0bfbbaf35d0565755b0e58`;
- `README.md`, `02-block-structure.md`, `03-content-distribution.md` и `new-note-workflow.md` совпадали с historical commit `0731611ce5b6e1997207ef588cf3c43a6d766609`;

Комплект описывает прежнюю модель, в которой один исполнитель самостоятельно выполнял анализ, редактирование, повторную проверку и финальное решение. Он сохранён для provenance и возможного осознанного восстановления автономного режима в будущем.

Архив:

- не является текущей инструкцией;
- не должен автоматически загружаться Codex или ChatGPT Web;
- не участвует в обычной работе с заметками;
- не переопределяет `AGENTS.md` и активные файлы `governance/`.
