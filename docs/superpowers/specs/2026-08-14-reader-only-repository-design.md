# Читательский состав репозитория

## Цель

Текущее дерево GitHub должно содержать только материалы, необходимые для чтения конспекта: корневой `README.md` и каталог `notes/` со страницами разделов и заметками.

Правила переработки, планы, скрипты и настройки обслуживания остаются в локальной рабочей папке, но перестают отслеживаться Git и не отображаются на GitHub.

## Публичный состав

В Git остаются:

- `README.md`;
- `notes/**`.

Корневой `README.md` уже содержит только читательскую навигацию и не требует изменения.

## Локальный служебный состав

На диске сохраняются, но удаляются из индекса Git:

- `_templates/**`;
- `docs/**`;
- `scripts/**`;
- `.github/**`;
- `.gitignore`;
- `.gitattributes`.

Эти пути добавляются в локальный `.git/info/exclude`. Благодаря этому обычные `git add` не вернут служебные файлы в публичный репозиторий. Исключения действуют только для текущего клона и сами не публикуются.

## Порядок изменения

1. Добавить служебные пути в `.git/info/exclude`.
2. Удалить их только из индекса Git, сохранив физические файлы.
3. Убедиться, что все локальные служебные файлы по-прежнему доступны.
4. Запустить локальные проверки навигации и заметок.
5. Проверить, что список отслеживаемых файлов состоит только из `README.md` и `notes/**`.
6. Зафиксировать очистку и напрямую отправить её в `origin/main` без Pull Request.

## Критерии готовности

- текущая страница репозитория GitHub показывает только `README.md` и `notes/`;
- все 262 заметки и README разделов сохранены;
- навигационные ссылки проходят штатную проверку;
- служебные файлы существуют локально;
- `git status` не предлагает добавить локальный служебный слой;
- `origin/main` указывает на проверенный итоговый коммит.
