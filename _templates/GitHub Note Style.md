# Стиль материалов для GitHub

Служебный шаблон фиксирует структуру опубликованных Markdown-страниц. Он не добавляется в навигацию репозитория.

## Заметка

<!-- NOTE-NAV-TOP:END -->

## Страница раздела

- H1 совпадает с названием раздела.
- Порядок стрелочной навигации берётся из списка ссылок на странице раздела.
- Возврат ко всем разделам, количество заметок и переход к первой теме создаются автоматически.

## Главная страница

- Короткое описание конспекта.
- Разделы объединены в три смысловые группы.
- Поиск, служебные команды и длинные инструкции не добавляются.

## Правила поддержки

- Материалы редактируются непосредственно в `notes`.
- Новую заметку нужно добавить в нужное место списка на странице раздела.
- Стрелки между заметками, количество материалов и ссылка на первую тему обновляются командой `python scripts/generate_navigation.py`.
- После изменений запускаются `python scripts/generate_navigation.py --check` и `python scripts/check_notes.py`.
- Внутренняя ссылка должна вести на существующую связанную тему; изолированные карточки запрещены автоматической проверкой.
