# Codex instructions

В этом репозитории Codex является ограниченным исполнителем, а не владельцем смыслового ревью заметок.

Перед выполнением задачи прочитай:

1. [`governance/codex-execution.md`](<./governance/codex-execution.md>);
2. [`governance/repository-rules.md`](<./governance/repository-rules.md>);
3. только те структурные правила из [`governance/web-review/`](<./governance/web-review/>), на которые прямо ссылается текущая Web-инструкция.

ChatGPT Web владеет:

- границей темы и составом материала;
- технической и смысловой оценкой заметки;
- понятностью, последовательностью, смысловой нагрузкой и избыточностью;
- решениями `PASS`, `FAIL`, `NOT CHECKED` и `READY`;
- проектированием окончательной содержательной правки.

Codex может самостоятельно выполнять только явно разрешённый режим исполнения: точное применение Web-кандидата, детерминированную структурную правку, ограниченную реализацию кода либо штатное репозиторное обслуживание.

Обычная задача над заметкой не изменяет `AGENTS.md`, `governance/**`, `.github/**` или `scripts/**`, если Web-инструкция прямо не включает эти пути в scope.

Если semantic scope, точный base, разрешённый режим или требуемый результат неоднозначны, верни `STOP`, а не принимай новое содержательное решение.
