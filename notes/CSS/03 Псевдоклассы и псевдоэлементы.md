# Псевдоклассы и псевдоэлементы

## Быстрый ответ

Псевдокласс выбирает существующий элемент по состоянию, положению или условию: `:hover`, `:focus-visible`, `:checked`, `:nth-child()` или `:has()`. Псевдоэлемент выбирает часть элемента либо создаваемый CSS фрагмент, например `::first-line`, `::placeholder`, `::before` или `::after`.

Короткая граница: псевдокласс меняет условие выбора самого элемента, а псевдоэлемент задаёт, какую его часть нужно стилизовать. Эти возможности уменьшают потребность в служебной HTML-разметке, но не заменяют семантические элементы и JavaScript-состояние приложения.

## Ключевая схема

| Тип | Синтаксис | Примеры |
| --- | --- | --- |
| Псевдокласс | `:` | `:hover`, `:focus`, `:not`, `:has` |
| Псевдоэлемент | `::` | `::before`, `::after`, `::placeholder` |

## Базовая модель

В селекторе сначала находится реальный элемент. Псевдокласс проверяет дополнительное условие для этого элемента. Псевдоэлемент после выбора элемента обращается к определённой части его представления, которая не обязана быть отдельным DOM-узлом.

Например, `button:hover` выбирает кнопку, на которую наведён указатель, а `button::before` создаёт перед содержимым кнопки CSS-generated box, если свойство `content` не равно `none`.

## Развернутый ответ

Псевдокласс выбирает сам элемент по состоянию, положению или условию: `:hover`, `:focus-visible`, `:checked`, `:nth-child`, `:has`. Псевдоэлемент стилизует виртуальную часть элемента: `::before`, `::after`, `::placeholder`, `::selection`.

`:is()` группирует селекторы и берёт специфичность самого специфичного селектора внутри. Он помогает писать короче, но может поднять вес правила, если внутри оказался id или сложный селектор.

`:where()` тоже группирует селекторы, но всегда имеет нулевую специфичность. Это удобно для base styles, reset и правил, которые должны легко переопределяться компонентами.

`:has()` выбирает элемент, если относительно него находится совпадение с указанным селектором. Его часто называют parent selector, но он шире: условием может быть потомок, непосредственный ребёнок или следующий сосед.

Псевдоэлементы `::before` и `::after` используют для декора и дополнительных визуальных деталей. Важный текст и интерактивные элементы следует оставлять в HTML: generated content не даёт надёжной семантики и не должен быть единственным источником информации.

`:focus-visible` показывает focus indicator, когда браузер считает его необходимым с учётом способа взаимодействия и своих эвристик. Это не точный синоним «фокус с клавиатуры». Для доступности нельзя удалять outline без полноценной видимой замены.

## Пример

```css
button:focus-visible {
  outline: 2px solid dodgerblue;
}

.field:has(input:invalid) {
  color: crimson;
}

.badge::before {
  content: "";
  display: inline-block;
  width: 8px;
  height: 8px;
  border-radius: 50%;
  background: currentColor;
}
```

Первое правило сохраняет видимый фокус там, где он нужен пользователю. Второе стилизует поле-контейнер, если вложенный `input` не проходит встроенную HTML-валидацию. Третье добавляет декоративную точку, не создавая отдельный элемент в DOM.

## Ключевые уточнения

- `:` относится к псевдоклассу, `::` - к псевдоэлементу; старый одноточечный синтаксис поддерживается лишь для некоторых ранних псевдоэлементов.
- `:focus-visible` следует браузерным эвристикам, а не только типу устройства ввода.
- `:is()`, `:not()` и `:has()` влияют на специфичность через свои аргументы; `:where()` всегда имеет нулевой вес.
- `::before` и `::after` создают box только при подходящем значении `content`.
- Generated content подходит для оформления, но не для незаменимой информации или интерактивности.
