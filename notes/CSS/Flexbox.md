## Быстрый ответ

Flexbox - это CSS-модель раскладки для одномерного распределения элементов: либо по строке, либо по колонке. Она удобна, когда нужно выровнять элементы, распределить свободное место, сделать адаптивную строку карточек, меню, toolbar или центрирование.

Главное помнить: у flex-контейнера есть главная ось и поперечная ось. `flex-direction` задает направление главной оси, `justify-content` выравнивает по главной оси, а `align-items` - по поперечной. Размеры элементов управляются через `flex-basis`, `flex-grow` и `flex-shrink`. В отличие от Grid, Flexbox обычно решает раскладку в одном направлении, поэтому для сложной сетки из строк и колонок чаще выбирают Grid.

## Ключевая схема

| Задача | Свойство |
| --- | --- |
| Включить flex-контекст | `display: flex` |
| Направление главной оси | `flex-direction` |
| Выравнивание по главной оси | `justify-content` |
| Выравнивание по поперечной оси | `align-items` |
| Перенос на новую строку | `flex-wrap` |
| Базовый размер элемента | `flex-basis` |
| Рост элемента | `flex-grow` |
| Сжатие элемента | `flex-shrink` |
| Короткая запись | `flex: grow shrink basis` |

## Развернутый ответ

Flexbox строится вокруг главной и поперечной осей. `flex-direction` задаёт главную ось: при `row` она горизонтальная, при `column` вертикальная. `justify-content` работает вдоль главной оси, а `align-items` - вдоль поперечной. Поэтому после смены `flex-direction` визуальный смысл выравнивания меняется.

Размер flex-item рассчитывается через `flex-basis`, `flex-grow` и `flex-shrink`. `flex-basis` задаёт базовый размер до распределения свободного места, `flex-grow` описывает рост, `flex-shrink` - сжатие. Короткая запись `flex: 1` обычно означает `1 1 0%`, поэтому элементы делят свободное место от нулевой базы.

`flex-wrap` нужен, когда элементы не должны сжиматься до нечитаемого размера. Тогда они переносятся на новую строку. Без `min-width: 0` длинный текст внутри flex-item может не сжиматься и ломать контейнер, потому что минимальный размер по содержимому мешает shrink.

Flexbox удобен для toolbar, navbar, ряда карточек, распределения свободного места и центрирования. Для полноценной двумерной сетки, где одновременно важны строки и колонки, чаще подходит Grid.

<details>
<summary><strong>Уточнения</strong></summary>

- `justify-content` выравнивает по main axis, `align-items` - по cross axis.
- `flex: 1` обычно раскрывается как `flex: 1 1 0%`.
- `flex-wrap` разрешает перенос элементов.
- `min-width: 0` часто нужен flex-item с длинным текстом.
- Flexbox одномерен, Grid управляет строками и колонками одновременно.

</details>

## Пример

```css
.toolbar {
  display: flex;
  align-items: center;
  gap: 12px;
}

.toolbar__title {
  flex: 1 1 auto;
}

.toolbar__actions {
  display: flex;
  gap: 8px;
}
```

В этом примере заголовок занимает доступное пространство, а кнопки остаются справа и выравниваются по центру высоты.

## Частые ошибки

- Путать главную и поперечную ось после изменения `flex-direction`.
- Использовать Flexbox для полноценной двумерной сетки, где проще применить Grid.
- Забывать `min-width: 0` у flex-элемента с длинным текстом, из-за чего текст ломает контейнер.
- Ставить `flex: 1`, не понимая, что базовый размер становится `0%`.
- Ожидать, что `align-items` выровняет элементы по главной оси.
