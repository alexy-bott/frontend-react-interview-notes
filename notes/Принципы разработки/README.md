### 2. Ограничение сложности

### 3. Сборка решения из частей

Принципы не применяются изолированно. SOLID помогает увидеть связанность и нестабильный контракт, DRY/KISS/YAGNI проверяют цену предлагаемой абстракции, а композиция даёт способ собрать решение без жёсткой иерархии.
