## Быстрый ответ

Функция в JavaScript - вызываемый объект и значение первого класса (first-class value): её можно присвоить переменной, передать аргументом, вернуть из другой функции и хранить в объекте. При вызове создаётся новый контекст выполнения (execution context) с параметрами, локальными привязками, `this` для обычной функции и ссылкой на внешнее лексическое окружение.

Function declaration (объявление функции) создаётся вместе с функцией при подготовке области, поэтому доступно до своей строки. Function expression (функциональное выражение) и arrow function (стрелочная функция) создаются при вычислении выражения; момент их доступности определяется привязкой, в которую записан результат.

Обычная функция получает собственный `this` по форме вызова и имеет `arguments`. Стрелочная функция не создаёт собственные `this` и `arguments`, а использует их из внешней области; у неё нет `prototype`, и вызвать её через `new` нельзя. Стрелки удобны для callback-функций и лексического `this`, краткая запись метода - для методов с `this`, а объявление или выражение выбирают по нужной области видимости и моменту создания функции.

## Ключевая схема

| Форма | Момент создания | Собственный `this` | Можно вызвать с `new` |
| --- | --- | --- | --- |
| `function fn() {}` | при подготовке области | да | да |
| `const fn = function () {}` | при вычислении выражения | да | да для обычного функционального выражения |
| `const fn = () => {}` | при вычислении выражения | нет | нет |
| `{ fn() {} }` | при создании объекта | да | нет |
| `async function fn() {}` | зависит от объявления или выражения | да | нет |
| `function* fn() {}` | зависит от объявления или выражения | да | нет |

## Базовая модель

Вызов функции связывает аргументы с параметрами, создаёт локальные привязки и выполняет тело до `return`, исключения или конца функции. Обычная функция без явного `return` возвращает `undefined`. Каждый вызов получает собственные локальные привязки, поэтому рекурсивные и параллельно ожидающие async-вызовы не делят одну локальную переменную автоматически.

Функция сохраняет ссылку на лексическое окружение места создания. Благодаря этому её код может читать внешние привязки после выхода из внешней функции; это называется замыканием (`closure`). Значение `this` обычной функции, напротив, определяется формой вызова, а не лексической областью видимости.

Аргументы передаются по значению. Если аргумент является объектом, параметр получает объектное значение, предоставляющее доступ к той же сущности. Переназначение параметра не меняет переменную вызывающего кода, но мутация общего объекта видна снаружи.

## Развернутый ответ

### Объявление и функциональное выражение

```js
sayHi(); // ok

function sayHi() {
  console.log("Hi");
}

sayBye(); // ReferenceError

const sayBye = function () {
  console.log("Bye");
};
```

Объявление функции удобно использовать для именованной операции уровня текущей области. Функциональное выражение подчёркивает, что функция создаётся как значение: для callback-функции, условной конфигурации, фабрики или присваивания свойству. Именованное функциональное выражение также даёт имя для рекурсии и стека ошибки (`stack trace`), не создавая это имя во внешней области.

### Обычная функция и стрелка

```js
const user = {
  name: "Ann",

  regular() {
    return this.name;
  },

  arrow: () => {
    return this.name;
  },
};

user.regular(); // Ann
user.arrow(); // undefined в ES module
```

`regular` вызвана как метод и получает `this === user`. Литерал объекта не создаёт отдельный `this`, поэтому `arrow` берёт его из внешней области модуля, где верхнеуровневый `this` равен `undefined`.

### Параметры и аргументы

Параметры могут иметь значения по умолчанию, а rest-параметр собирает оставшиеся аргументы в настоящий массив. В обычной, не стрелочной функции доступен массивоподобный объект `arguments`, но rest-параметр явнее показывает контракт и поддерживает методы массива.

```js
function sumOld() {
  return Array.from(arguments).reduce((acc, value) => acc + value, 0);
}

const sum = (...numbers) =>
  numbers.reduce((acc, value) => acc + value, 0);
```

Начальное значение параметра вычисляется только при аргументе `undefined`, но не при `null`. Rest-параметр должен быть последним и не может иметь значение по умолчанию.

### Передача объекта аргументом

```js
function update(user) {
  user.name = "Kate";
  user = { name: "Other" };
}

const user = { name: "Ann" };
update(user);

console.log(user.name); // Kate
```

Мутация работает с общей объектной сущностью. Последующее переназначение локального параметра `user` не меняет привязку снаружи функции.

### Функции-конструкторы, async functions и генераторы

Не каждая функция является конструктором. Обычные объявления функций и функциональные выражения обычно поддерживают `new`; стрелочные функции, методы, async functions и генераторы - нет. Для прикладных моделей объектов современный код чаще использует `class`, но механизм наследования по-прежнему опирается на цепочку прототипов.

```js
function User(name) {
  this.name = name;
}

const user = new User("Ann");
```

Async function всегда возвращает `Promise`: `return` задаёт значение выполненного Promise, а необработанный `throw` - причину отклонения. Вызов функции-генератора не выполняет тело сразу, а возвращает итератор; тело продвигается вызовами `next()`.

```js
async function load() {
  return 1;
}

load().then(console.log); // 1
```

## Где применяется во frontend

| Ситуация | Форма | Причина |
| --- | --- | --- |
| Callback без собственного `this` | стрелочная функция | сохраняет внешний `this`, компактно выражает вычисление |
| Метод объекта | краткая запись метода | получает `this` из вызова `obj.method()` |
| Переиспользуемая операция в области | объявление функции | доступна во всей области и имеет имя в стеке ошибки |
| Функция как условно создаваемое значение | функциональное выражение | момент создания явно следует потоку выполнения |
| Асинхронная последовательность | async function | связывает `await`, `return` и `throw` с Promise |

## Ключевые уточнения

- Объявление функции доступно при подготовке области, а функциональное выражение создаётся при вычислении выражения.
- Стрелочная функция не имеет собственных `this`, `arguments` и `prototype` и не вызывается через `new`.
- Кратко записанный метод имеет динамический `this`, но сам метод не является конструктором.
- Аргументы передаются по значению; объектный аргумент даёт функции доступ к общей объектной сущности.
- Async function всегда возвращает `Promise`, даже если `return` содержит обычное значение.
