## Маршрут изучения

1. Типы, преобразование значений и сравнение.
2. Области видимости, hoisting, функции, `this` и замыкания.
3. Объекты, прототипы, классы, дескрипторы и неизменяемость.
4. Массивы, коллекции, итераторы и встроенные типы данных.
5. Модули и загрузка скриптов.
6. Event Loop, Promise, `async/await`, таймеры и отмена.
7. DOM, события, Observer APIs, Streams API и обмен сообщениями.
8. Память, производительность и связанное устройство браузера.
